# Provenance

The Aliyun Dysmsapi V2 request wire format was adapted from the owner's CubeRoot SMS transport (GPL-3.0-only). The Tencent SendSms request/response adapter is a new generic implementation against Tencent Cloud's public API contract; it contains no Mira application source, credentials, templates or user records.

Provider-specific account settings, SDK construction, application verification state and delivery callbacks remain outside this package. See LICENSE for the GPL-3.0-only terms.
