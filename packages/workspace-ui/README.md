# Workspace UI

React panels for projects, work reports, discussion and revision history. Hosts inject their own API, links, navigation, button and translator. Import workspace.css and map --workspace-* tokens to the host theme. Authentication, members, permissions enforcement, storage and migrations belong to each independent application. This package has no environment access or product imports.

Local candidate 0.1.0; no production publication has occurred. The owner explicitly extended Foundation from server-only libraries to shared UI for this task.
